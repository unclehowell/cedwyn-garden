## Where the live /garden/ page comes from (checked 9 Nov 2026)

The live page at https://cedwyn.bucklerfamily.estate/garden/ ("The Flower Garden") is built from `web/garden/index.html` on `unclehowell/cedwyn` `main`, with its styles and works list in the shared `web/_cedwyn/flower-gallery/` folder (the same `artworks.json` that `unclehowell/cedwyn-arcade` carries).

This repository is a copy of the old `garden` branch (see `SPLIT.json`, 5 Nov 2026). The build does not read that branch, so a change made here does not reach /garden/. To change the live Flower Garden, open a PR on `unclehowell/cedwyn` `main` against `web/garden/index.html` or `web/_cedwyn/flower-gallery/`.
